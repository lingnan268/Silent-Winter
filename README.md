Q：小陀螺为什么给传统自瞄算法带来巨大挑战？
A：小陀螺作一个作高速旋转的物体，在他旋转的同时所装配的装甲板也会随着他进行高速的旋转，而在自瞄算法的基本原理上，它是由相机拍摄到画面，到检测到敌方装甲板，再到算出装甲板的位置，根据当前位置检测下一位置，最后告诉云台向哪里转，最后发射子弹，是有一定的过程的，而这所有的过程都是需要时间的。传统的算法更倾向于假设目标做的是相对平稳的运动，而没有太剧烈的动感所产生的一切特性。所以传统的算法不适合面对小陀螺这种高速旋转，并且给视觉算法带来诸多负面影响的运动。在小陀螺的机制中机器人原地高速旋转，这个时带来的第一个负面影响，就是高速旋转的同时拍摄到的装甲板，还有上传的影像会变得模糊，传感器上的像会拖成一片，而装甲板上的灯带本来是清晰的亮线条，在这里就会被拖成一条模糊的光带，或者变成模糊的弧线，甚至变得难以检测，这种模糊会一直传下去，从画面模糊到装甲板检测不准，再到角点的位置偏移，最后预测出错很难打中。第二点，装甲板不是直线运动，而是圆周运动，也就代表在机器人旋转的时候，每块装甲板都在做圆周运动，不能够用直线模型去预测圆周轨迹。第三点，在做圆周运动的同时，装甲板会不断的出现和消失，这个时候检测到的画面，就是模糊的灯条一会儿出现一会儿消失，很难稳定的持续跟踪。第四点，id跳变的问题，跟踪算法给每块装甲板分配一个id持续跟踪，但是在装甲板高速旋转的同时，一块板刚转出视野另一块板又迅速转进来，算法很容易搞混最终导致重新分配id，id出错就无法实现稳定的追踪检测打击，因为算法很可能把两块不同装甲板的位置变化，当成了同一块的运动轨迹。第五可打击的时间很短只有在装甲板正对着的时候或者说稍微有些偏离的时候才能被打中机器人高速旋转的时候每块装甲板能够打击的时间很短，这还要考虑到画面的上传，云台的转动，以及弹丸发射所需要的时间，这里面的时间很难去精确地估算，如果在装甲板正对着发射弹丸的机器人的时候，机器人才会做出发射弹丸的决策，那么很可能这一块装甲板已经转走，而原本要打击的位置正处于两个装甲板之间，很难凭借运气击中。最后的难点所也不仅仅在于机器人的高速旋转，更在于对装甲板出现的时间的判定，以及对弹丸发射出去后飞行的时间估算，怎样才能让弹丸能够更为精准命中装甲版。
Q：图像分类和目标检测的核心区别是什么？
A：图像分类是把检测到的图像归为一个类别，贴上一个标签。而目标检测是搜寻整个图像里面需要检测到的目标，确定它的位置。
Q：工业相机在成像时会出现镜头畸变。请解释什么是畸变，并且为什么不用内参标定的方法就会影响测距精度？
A：相机的镜头是玻璃制成的曲面，光经过曲面会发生折射弯曲，从而导致成像畸变。畸变一般分为两种，第一种径向畸变的导致原因是，相机的镜头是圆的，也就是中边厚两边薄，光线在经过镜头边缘的时候，发生的弯曲程度会比中间要大，这就导致边缘的参数和中间的参数不统一，发生变形。第二种是切向畸变，由于镜头和感光元件不平行而导致，于是画面整体偏移，一些画面被压缩，一些画面被拉伸。内参标定一般是指用棋格盘来拍标定板，算法会计算出两套参数，一套是相机内参，用来描述相机成像的几何关系，一套是畸变系数，用来描述成像的畸变程度。如果不去标定，那么首先相机畸变导致成像的位置出现偏差和错误，其次没有参数就无法进行PnP运算，最后成像畸变从二维到三维的过程中还会被持续放大误差。要想精度高就必须要去标定内参。
Q：solvePnP是视觉算法组进行位资估计的常用函数，简述一下调用这个函数结算时需要哪些输入，二维角点误差为什么会导致三维位置抖动？
A： solvePnP是指一个物体的3d模型，并且看到了它在照片里的2d投影，反推出这个物体相对于相机的位置和姿态。比如知道一块装甲板的真实尺寸，在画面里看到了他的四个角点，然后要回答这块装甲板离相机多远，朝哪个方向偏了多少度。他需要的输入参数有objectPoints，物体特征点的3d坐标，比如装甲板四个角点的真实坐标。imagePoints，这些点在图像中的2d像素坐标，是装甲板四个角点在画面里的像素位置。camera Matrix，相机内参矩阵，标定后得到fx fy cx cy包含焦距和光心。distCoeffts，畸变系数，标定后得到k1 k2 p1 p2 p3...输出的参数则是旋转向量，也就是物体相对相机转了多少度，还有平移向量，也就是物体相对相机的3d位置，距离和偏移。至于为什么2d角点误差会导致3d位置抖动，第一个方面是因为2d到3d不是线性映射，而是把3d到2d的投影反过来求3d，线性关系的误差不会被放大，但非线性关系的误差可能会被放大很多。第二个方面是因为距离越远放大越严重，距离近的时候标定的点的位置在像素的空格里占用的范围很少，但是距离远的时候像素集成一团，这个时候稍有偏差可能就不只是一两个格子的偏差。第三个方面是每帧都有随机误差，所以表现为抖动，角点检测的不完美使得每一帧的2d角点位置都有微小的随机误差。每一帧的误差方向和大小都不同，所以每一帧PnP算出来的3d位置都不一样，表现为位置在真实值附近来回跳动产生抖动。
Q：在目标运动预测时为什么不能只用相邻两帧位置差计算目标速度，并简述一下卡尔曼滤波在这个场景下的工作原理及作用。
A：每一帧PnP算出来的3d位置都有随机误差，两个位置相减除以时间间隔后，速度误差会被放大，位置本身就有噪声，两个噪声位置相减噪声不会消除，反而可能因为正负不同叠加。且如果某一帧检测出现了问题，比如装甲板被遮挡了，或者角点检测跑偏了，那么这一帧的位置就是错的，只有两帧的话一个坏的数据就毁掉了整个的速度估计。并且目标可能会在做变速运动，比如加速减速或者转弯，两帧只能告诉瞬间的速度是多少，捕捉不到加速还是减速，方向会不会改变自瞄需要预测目标未来的位置只靠两帧瞬时速度做预测是不行的。卡尔曼滤波的核心是预测和修正的循环，也就是先用过去的运动状态预测现在在哪儿，再用相机实测到的位置去修正预测。第一步，根据上一帧的位置和速度，推算这一帧目标应该在什么位置。第二步则是如果相机检测到了目标的实际位置，卡尔曼滤波会做一个加权平衡，如果预测比较准就多信预测，如果测量比较准就多信测量。在卡尔曼滤波的作用下，加权平均，噪声被平滑掉，异常值可以被预测拉回来，影响有限，并且能够积累历史信息使速度越来越稳，综上也就是减少单帧异常的影响，积累历史的预测和实际信息并且让预测更准。它能让PnP输出的抖动位置变得平滑，不只是知道在哪儿还知道往哪儿走，走多快，更多的是弹丸飞到目标需要时间，卡尔曼滤波能够算出弹丸到达时目标在哪儿。
